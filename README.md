A one-page poster summing up the world news of Wednesday 18 November 2026: five verified stories — the Gulf all-clear after US–Iran strikes, the crippled Crimea bridge, Trump's Asia tour opening in Manila, Nvidia's record quarter and its board ruling out a Huang comeback, and Cyclone Akvan bearing down on India's east coast. Every story was checked against a source article dated 18 November 2026, and all artwork is drawn in code — no photographs or copied images.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The program copies the rendered poster to `entry.png` in the output directory. The poster source lives in `poster/` (HTML/CSS, including hand-drawn SVG icons); `tools/capture.mjs` renders it to `entry.png` at 1024×1024 with headless Chrome.
